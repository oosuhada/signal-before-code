# Visual intuition index

These traces are not animations for decoration. Each one exposes the state that justifies the next
algorithmic move. The same examples are generated by `signal_before_code/tracing.py` and can be run
interactively with `scripts/trace.py`.

```bash
python3 scripts/trace.py binary-search
python3 scripts/trace.py bfs --step
python3 scripts/trace.py dijkstra --predict
python3 scripts/trace.py dp-grid
```

`--predict` intentionally hides the transition until Enter so the learner must name the next move
from the invariant instead of passively reading it.
