## Learning question to earn the chapter

When a problem repeatedly asks about a **contiguous interval**, what information can be updated as
the interval moves instead of recomputed from scratch?

Before promoting this scaffold, a real learning session should produce:

- one naive repeated-interval approach;
- the exact condition that makes a fixed or variable window valid;
- a counterexample where negative values or non-monotonic state break a naive window rule;
- at least two candidate approaches;
- a hand walkthrough;
- a `When NOT to use it` section;
- one mutation that shifts toward prefix sums, hashing, or a monotonic queue;
- real Understand / Recognize / Apply attempt records.

Practice candidates are already curated in [`../../curriculum/problems.json`](../../curriculum/problems.json)
so the next session can begin without auto-generating the explanation first.
